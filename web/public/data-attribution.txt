Campus WebGIS - Data attribution and source notice

This is an independent campus visualization and GIS demonstration, not the university's official website.
The following source credits are retained from the original campus export LICENSE.txt. They describe the input datasets, not a license for all application source code.

The original export was provided through topoexport.com. Original LICENSE.txt requires rigorous checks with surveyors before using these datasets because exported files can contain anomalies, inaccuracies and approximations.

Project additions: campus plan georeferencing, simplified landmark reconstruction and sports geometry. Some dimensions and positions are schematic-derived estimates, not official survey measurements. The user has confirmed permission to redistribute the campus GLB and GIS datasets with required attribution. Reference photos are not republished here.

Statistics use EPSG:32650 (UTM Zone 50N, meters). Road lengths and mapped green/water areas are sums of the recorded features, not complete cadastral or land-use inventories. Four stadiums are represented by eight track/pitch polygons.
